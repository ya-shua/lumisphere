# 微光域 · 对接说明

给她一片可以自由浏览、又不会打扰主机的专属空间。它自己是一个浏览器自动化服务：
控制端口 `127.0.0.1:8765` 收指令，浏览器用独立的 `data/profile`（不跟你的浏览器混），窗口默认藏起来。

## 一、怎么接

### 1. HTTP（最主要，人也能用）

面板：浏览器打开 <http://127.0.0.1:8765/>（只允许本机访问）。

| 要干的事 | 怎么调 |
|---|---|
| 打开网页 | `POST /open {"url": "https://..."}` |
| 搜索 | `POST /search {"q": "..."}` |
| 抓正文 | `POST /fetch {"url": "https://..."}` |
| 截图 | `GET /screenshot`（PNG） / `GET /screenshot/base64` |
| 标签页 | `GET /tabs`、`POST /tabs/clean` |
| 视频抽帧 | `POST /video/frames {"url": ...}`、`GET /video/probe` |
| 登录检测 | `GET /login/detect`、`POST /login/notify`、`POST /login/wait` |
| 藏/显示浏览器窗口 | `POST /window/hide`、`POST /window/show` |
| 读配置 / 退出 | `GET /api/config`、`POST /quit` |
| 身份与能力 | `GET /api/health`、`GET /api/manifest` |

默认「本机模式」不校验令牌；切成 bridge 模式才要求 `X-Auth-Token`。

### 2. MCP（海螺当工具用）

海螺的 `plugins/lumisphere` 段拉起来后有 12 个工具（打开/搜索/抓取/截图/标签页等），
工具名以 `POST /api/manifest` 返回的 `capabilities` 为准。

### 3. 事件

没有事件总线。要「她看到什么」就拉 `GET /tabs` 或 `GET /status`。

## 二、能力清单

- 打开网页、切标签页
- 搜索并抓正文
- 截图（PNG / base64）
- 视频抽帧与探测
- 登录状态检测与等待

## 三、失败语义

| 情况 | 返回 | 调用方怎么做 |
|---|---|---|
| 浏览器没起来 / 崩了 | `{"error": ...}`，`browser_ok: false` 在 `/api/config` 里 | 先 `POST /browser/start`，再重试一次 |
| 页面加载超时 | `{"error": "..."}` | 可以重试；连续两次就放弃并告诉她 |
| 非本机来源 | `403` | 别绕过，这是设计 |
| bridge 模式没带 token | `401` + hint | 补 `X-Auth-Token` |

**不可逆动作**：`POST /quit`（关服务）。其他都是只读或可恢复。

## 四、单独运行（不装海螺）

```powershell
cd <插件目录>\微光域
.\.venv\Scripts\python.exe main.py
```

需要本机有 Edge（Playwright 用系统浏览器）。起来后浏览器开 `127.0.0.1:8765` 就是控制台；
窗口默认被藏起来，点托盘「显示浏览器」可以叫出来。

## 五、自检

```powershell
curl http://127.0.0.1:8765/api/health
curl http://127.0.0.1:8765/api/manifest
```
