# 微光域（LumiSphere）· 部署&使用文档

标语：LumiSphere · 给她一片可以自由浏览、又不会打扰你主机的专属空间。

## 1. 项目简介

LumiSphere 是轻量化AI隔离浏览沙箱，配套视觉理解插件运行。

AI在沙箱内部拥有页面完整操控权限，可自动滑动、点击、抽帧送入VLM理解视频与网页内容；沙箱之外严格限制权限，无法触碰宿主系统文件与其他软件。

可独立运行，也可通过Webhook联动 LumiCabin 壁纸，同步角色动作。

## 2. 环境要求

- Python 版本 >= 3.10
- 依赖库：playwright、pystray、pywin32、pyyaml
- 浏览器内核：Chromium（由 playwright 自动安装）
- 备选隔离方案：Windows Sandbox（仅 Windows 专业版/企业版支持，家庭版默认无此功能）
- 视觉能力：本地VLM模型 或 在线视觉模型API
- 网络：必须联网，用于访问目标网页、调用视觉模型

## 3. 部署步骤

1. 下载完整项目包，保持目录结构
2. 安装Python依赖

```bash
pip install playwright pystray pywin32 pyyaml
playwright install chromium
```

3. 编辑 `config.yaml` 配置文件
   - 沙箱模式：选择 `playwright`（推荐）或 `windows_sandbox`
   - 域名白名单：填写允许访问的网站域名
   - 视觉插件：配置 VLM 接口地址、抽帧频率、提示词模板
   - Webhook 推送：开启推送，填写 LumiCabin 的接收地址
4. 启动主程序

```
python core/sandbox.py
```

5. 系统托盘操作
   - 启动后右下角出现 LumiSphere 托盘图标
   - 双击图标：显示 / 隐藏浏览器窗口
   - 右键菜单：暂停任务、清空沙箱数据、退出程序

## 4. 窗口模式说明

- 有头模式（默认）：浏览器窗口可见，可最小化到任务栏，也可通过托盘隐藏窗口、移除任务栏图标；隐藏后自动化、截图、抽帧功能不受影响
- 无头模式：后台静默运行，无窗口；存在截图越界风险，仅推荐高级用户调试使用

## 5. 联动 LumiCabin

任务启动、切换、结束时自动推送标准 Webhook 事件，协议与 LumiCabin 完全兼容，配置好地址即可开箱联动，无需额外开发。

## 6. 资源占用参考

| 模式 | 启动耗时 | 空闲内存 | 满载运行内存 |
| ---- | ---- | ---- | ---- |
| Playwright 有头 | 0.5 ~ 2 秒 | 150 ~ 300 MB | 400 ~ 800 MB |
| Windows Sandbox | 首次 15~30 秒，后续 5~10 秒 | 保底 2 GB | 2.5 ~ 4 GB |

## 7. 常见故障排查

1. 浏览器启动失败
   - 确认 playwright chromium 安装成功；重新执行 `playwright install chromium`
2. 截图黑屏
   - 无头模式下切换为有头模式；检查显卡驱动与硬件加速设置
3. 联动壁纸无反应
   - 检查 Webhook 地址、端口；确认 LumiCabin 已开启联动模式；检查防火墙拦截
4. 托盘图标不显示
   - 确认 pystray、pywin32 安装正确；Windows 通知区域图标设置中允许显示
