# 微光域（LumiSphere）· 安全边界与风险说明

## 1. 核心权限边界

### 沙箱内部允许的操作

- 页面内点击、滚动、跳转、多标签切换
- 页面级截图（仅截取当前浏览器页面内容）
- 视频/页面抽帧，送入VLM进行内容理解
- 访问配置白名单内的域名站点

### 沙箱默认禁止的操作

- 读取、修改、写入宿主本机的任何文件
- 捕获宿主桌面全屏画面、读取其他窗口内容
- 操控宿主系统的鼠标、键盘，操作其他软件
- 修改系统设置、注册表、启动项
- 下载文件到宿主机、上传本机文件到沙箱内
- 访问白名单以外的站点

## 2. 两种隔离方案的安全等级

### Playwright 模式（应用层隔离）

- 安全等级：中等
- 隔离原理：独立浏览器进程 + 代码层权限过滤
- 风险点：
  1. 若代码不严谨，误用全局截图接口，存在截取宿主桌面的风险
  2. 恶意网页可通过浏览器漏洞尝试越界（概率极低）
  3. 无法完全防御浏览器级别的 0day 漏洞
- mitigation：强制使用 page 级截图接口、增加权限过滤层、域名白名单管控

### Windows Sandbox 模式（系统级隔离）

- 安全等级：高
- 隔离原理：Windows原生轻量虚拟机，独立内核与系统环境
- 风险点：几乎不存在沙箱内程序突破到宿主的可能
- 局限性：启动慢、资源占用高，每次关闭数据全部销毁

## 3. 隐私安全说明

1. 页面截图与抽帧仅在沙箱内部处理，默认不上传到第三方服务器（取决于你使用的VLM模型位置）
2. 任务结束后自动清空浏览器Cookie、缓存、浏览记录，不留痕迹
3. Playwright模式下，严格禁止调用全局屏幕截图API，代码层面做强制校验
4. 不会主动采集、上传任何宿主系统的隐私数据

## 4. 使用安全建议

1. 日常开发与使用优先选择 Playwright 有头模式，兼顾性能与可控性
2. 不要随意添加不明域名到白名单，降低恶意网页风险
3. 运行不可信脚本、访问高风险站点时，切换到 Windows Sandbox 模式
4. 定期更新 playwright 与依赖库，修复已知安全漏洞
5. 视觉模型优先使用本地部署模型，减少画面数据外传

## 5. 免责说明

1. 沙箱仅做程序行为隔离，无法规避平台账号风控（如抖音账号限流、封号）
2. 因用户自行修改权限过滤代码、添加危险域名、使用非官方插件导致的安全问题，项目不承担责任
3. VLM模型的输出内容由模型本身决定，沙箱不对AI输出内容的合规性负责

## 6. 开发复用说明

项目在开源协议允许范围内，借鉴复用以下成熟开源组件：

- Playwright 浏览器自动化框架
- pystray + pywin32 系统托盘与窗口控制方案
- 通用 Webhook 推送模块
- 开源浏览器沙箱权限过滤逻辑

所有复用代码均遵循对应开源协议，标注来源，不使用闭源私有代码。
